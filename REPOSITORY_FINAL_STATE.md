# Repository Final State

This repository is the final self-contained snapshot of the original
`online-course-platform` project.

## What changed here

- `backend/` is now stored directly in this repository.
- `frontend/` is now stored directly in this repository.
- Git submodule wiring has been removed so this repository can be archived,
  cloned, and reviewed without depending on external child repositories.

## Follow-up development

Subsequent iteration should continue in the `anygroupx` organization:

- Main repository: `https://github.com/anygroupx/online-course-platform`
- Backend repository: `https://github.com/anygroupx/backend`
- Frontend repository: `https://github.com/anygroupx/frontend`

Treat this repository as the closing snapshot for the legacy line.
