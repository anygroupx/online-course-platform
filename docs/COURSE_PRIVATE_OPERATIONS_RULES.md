# 密价运营规则

所有金额用两位小数 BigDecimal，单笔上限 9999999999.99；累积统计采用更宽 DECIMAL。业务时间来自统一 Clock 与显式时区，默认 Asia/Shanghai，按秒保存，T 天为连续时长。

|模式|期限|资格与续期|
|---|---|---|
|PERMANENT_PREPAID|无人工补出的到期日|首次明确 NEW_DEPOSIT 或 EXISTING_BALANCE，无周期续期|
|TIME_PREPAID|1–3650 天|首次 N，续期 NONE/NEW_DEPOSIT/PERFORMANCE/MANUAL|
|PERFORMANCE_RENEWAL|1–3650 天|首次 N，独立正有效消费目标 M，预存不算消费|
|TIERED_PRICING|按对应组合规则|同家族档位与固定价格，复用同一资格和钱包|
|LEGACY_PERMANENT|逐值保留旧 validFrom/Until|隐藏兼容，不公开销售或猜测旧资格|

首次 NEW_DEPOSIT 资格为批准水位后的未重复认领成功转入减批准转回；EXISTING_BALANCE 为明确公示的可用余额政策。N=0 可获得资格。首次起点为真实最后达标时刻与允许生效时间的较晚者；延期前失去资格后重新达标采用新的真实时刻。

购买窗口为 `[start,end)`，暂停/终止及原钱包绑定必须同时通过核验。生效期的购买权与下一期消费目标独立，续期进度 PENDING 不取消当前购买权。有效消费为原期明确关联、存在同额原扣款、在截止内可信完成且未全额退款的净订单。归档继续参与核查。仅观察上界证明完成时保留实际时间未知，不以任务观察时间补造完成日期。

默认观察期 7 天。原期结束且全部订单终局，或观察截止到达，才能最终结算。原期未结束不能因零订单或全部完成而提前终局。即时升级以 supersededAt 与原 end 的较早者为有效结算边界。终局后新退款/事实只调整原统计并追加复核，不改原终局时间或撤回已执行下一期。

新增预存续期 R 使用原期 `[start,end)`、首次资格关闭水位之后的成功转入减同窗口批准转回，并排除其他资格已认领流水。允许负净统计。下一期从原 end 连续起算，迟到确认只取得剩余时长；SAME_VERSION 可提前排程，LATEST_PUBLISHED 按下一期起点选当时已发布且有效版本。无合适版本沿用原版并追加 FALLBACK，不隐式换档或模式。

人工补授必须原冻结 `allowManualGrant=true`、明确理由和合同审核、周期调整、结算执行三项当前权限。补授记录独立资格来源，不把原未达标消费或不存在预存改成达标。已批准补授不依赖自动创建开关。

升级默认 NEXT_TERM。现代目标必须同商品、同家族、更高档位；REVIEW_IMMEDIATE 只有来源政策允许且独立审核权限齐备时执行。DIFFERENCE 的新增门槛为 `max(目标N - 已证明原门槛基数,0)`，FULL_TARGET 为全部目标 N 新资金，EXISTING_BALANCE 为明确独立的余额政策。新增升级窗口从原资格关闭水位至生效前，未认领转入减批准转回；生效前再次核验。原订单不重新计价。旧协议转换以申请水位限定新转入，未知旧基数为零并要求代理本人明确提交和确认；后台指定不能冒充该确认。

自动续期/升档须独立全局开关与原发布快照同意。自动升档只取公开且资金达标的最近档位，同级多候选需人工选择。同来源只允许一份下一期；已有其他批准权益时返回冲突，不覆盖。转入认领只作资格解释，不扣本金或冻结余额。

未达标、到期及退出均保留余额。转回申请不移动资金，财务批准同事务写原双边账本、成功划转与 EXECUTED 状态；余额不足不伪装已执行。用户、协议、钱包和周期/申请使用统一锁序；外部调用在资金事务之外。

暂停/恢复/终止已接入原关系与周期；尚待完成的退款复核处理、旧配置同步、普通价显式购买、统计、通知和全部页面交付不得作为已实现功能开放灰度。完整证据见 TEST_REPORT。


原周期净事实复核由独立权限人工确认：未解决的原扣款/退款/履约矛盾不能被一句“已核对”跳过。解除后保留当前真实金额、原终局和已授予权益，未来新事实再次变化仍会生成复核。

当前密价不可用且冻结政策允许时，才允许显式普通价。当前有效期内专户不足不是资格失效，不提供静默或显式补差。现代私有报价的同组批量确认绑定原周期/规则/期限，物化激活的协议版本递增不会改变金融意图；改期或换周期仍需重新报价。
