## 🎨 设计语言

### 配色方案
```css
主色调：
- 紫色渐变：#667eea → #764ba2
- 蓝色渐变：#4facfe → #00f2fe
- 绿色渐变：#43e97b → #38f9d7
- 粉色渐变：#f093fb → #f5576c

辅助色：
- 成功：#67C23A
- 警告：#E6A23C
- 危险：#F56C6C
- 信息：#909399
```

### 圆角规范
- 小圆角：4px - 6px（标签、小按钮）
- 中圆角：8px（输入框、按钮）
- 大圆角：12px - 16px（卡片、对话框）

### 阴影规范
- 浅阴影：0 2px 8px rgba(0, 0, 0, 0.06)
- 中阴影：0 2px 12px rgba(0, 0, 0, 0.08)
- 深阴影：0 8px 24px rgba(0, 0, 0, 0.12)

### 动画效果
- 悬停上浮：translateY(-2px) ~ (-8px)
- 过渡时间：0.3s
- 缓动函数：cubic-bezier(0.4, 0, 0.2, 1)
