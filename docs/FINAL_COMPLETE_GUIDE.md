## 🚀 快速启动

### 方式1：一键启动（推荐）

**Windows**:
```bash
# 1. 导入数据库
mysql -u root -p online_course < database/schema.sql
mysql -u root -p online_course < database/init_test_data.sql

# 2. 启动后端
start-backend.bat

# 3. 启动前端
start-frontend.bat

# 4. 访问
http://localhost:5173

# 5. 登录
项目不提供默认管理员账号，请在部署后通过受控流程创建。
```

### 方式2：手动启动

```bash
# 后端
cd backend
mvn clean install
mvn spring-boot:run

# 前端
cd frontend
npm install
npm run dev
```

## 🎯 核心功能演示

### 1. 查课下单
```
操作流程：
1. 进入"查课/下单"页面
2. 选择课程平台
3. 输入账号信息（支持多行）：
   北京大学 student001 pass001
   清华大学 student002 pass002
4. 点击"查询课程"
5. 勾选课程
6. 点击"提交选中课程"
7. 自动为2个账号提交选中的课程！
```

### 2. 订单导出
```
操作流程：
1. 进入"订单管理"页面
2. 勾选要导出的订单
3. 点击"导出选中"按钮
4. 选择导出格式
5. 自动复制到剪贴板
6. 粘贴到其他平台使用
```

### 3. 价格查看
```
操作流程：
1. 进入"价格列表"页面
2. 查看所有平台价格
3. 对比不同费率价格
4. 查看自己的实际价格
```

### 4. 代理管理
```
操作流程：
1. 进入"代理管理"页面
2. 点击"开户"创建下级
3. 设置费率（不能低于自己）
4. 点击"充值"给下级充值
5. 系统自动按费率计算实际扣费
```
