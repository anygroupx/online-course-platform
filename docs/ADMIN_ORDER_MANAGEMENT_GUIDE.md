# 管理员订单管理功能使用说明

> 更新时间：2026-07-12
> Base：开发 `http://localhost:8080/api`，Docker `http://localhost:8082/api`
> 权限：管理员（角色 ADMIN / 历史逻辑可能校验特定用户）
> 完整 API 索引见 [API_DOCUMENTATION.md](./API_DOCUMENTATION.md)


## 功能概述
管理员订单管理功能为系统管理员提供了对自营平台订单的完整管理能力，包括订单查询、状态管理、批量操作、统计报表等功能。

## 访问方式
1. 使用管理员账号登录系统
2. 在左侧菜单选择"系统管理" → "订单管理"
3. 进入管理员订单管理页面

## 主要功能

### 1. 统计信息展示
- **总订单数**：平台所有订单的总数量
- **已完成订单**：已完成状态的订单数量
- **总营收**：已完成订单的总金额
- **今日订单**：今日创建的订单数量

### 2. 订单查询与筛选
- **订单编号**：精确搜索特定订单
- **平台筛选**：按课程平台筛选订单
- **学生账号**：按学生账号搜索
- **订单状态**：按订单状态筛选（待处理、进行中、已完成、已取消、失败）
- **对接状态**：按对接状态筛选（待对接、对接成功、对接失败、重复订单、已取消）
- **时间范围**：按创建时间范围筛选

### 3. 订单操作
- **查看详情**：查看订单的完整信息
- **修改状态**：强制修改订单状态（管理员权限）
- **修改对接状态**：强制修改对接状态（管理员权限）
- **添加备注**：为订单添加备注信息
- **补单操作**：重新提交订单（最多5次）

### 4. 批量操作
- **批量修改订单状态**：同时修改多个订单的状态
- **批量修改对接状态**：同时修改多个订单的对接状态
- **批量添加备注**：为多个订单同时添加相同备注
- **批量补单**：同时重新提交多个订单

## 操作步骤

### 查询订单
1. 在查询条件区域设置筛选条件
2. 点击"查询"按钮执行搜索
3. 点击"重置"按钮清空查询条件

### 修改订单状态
1. 在订单列表中找到目标订单
2. 点击"修改状态"按钮
3. 选择新的订单状态
4. 填写修改原因（可选）
5. 点击"确定"完成修改

### 批量操作
1. 在订单列表中勾选需要操作的订单
2. 点击"批量操作"按钮
3. 选择操作类型（修改状态/修改对接状态/添加备注）
4. 设置操作值和原因
5. 点击"确定"执行批量操作

### 添加备注
1. 点击订单的"添加备注"按钮
2. 在对话框中输入备注内容
3. 点击"确定"保存备注

## 权限说明
- 只有管理员（用户ID = 1）才能访问此功能
- 管理员可以查看所有用户的订单
- 所有操作都会记录到操作日志中

## 注意事项
1. **强制修改状态**：管理员修改订单状态会覆盖系统自动状态，请谨慎使用
2. **补单限制**：每个订单最多只能补单5次
3. **操作日志**：所有管理员操作都会自动记录，便于审计
4. **数据安全**：批量操作支持事务回滚，确保数据一致性

## 状态说明

### 订单状态
- **待处理**：订单已创建，等待处理
- **进行中**：订单正在处理中
- **已完成**：订单处理完成
- **已取消**：订单被取消
- **失败**：订单处理失败

### 对接状态
- **待对接**：等待与第三方平台对接
- **对接成功**：成功对接第三方平台
- **对接失败**：对接第三方平台失败
- **重复订单**：检测到重复订单
- **已取消**：对接已取消

## 技术特性
- **实时统计**：统计数据实时更新
- **高级筛选**：支持多条件组合查询
- **批量处理**：提高操作效率
- **操作日志**：完整的操作记录
- **权限控制**：严格的管理员权限验证
- **事务安全**：确保数据一致性

## 故障排除
如果遇到问题，请检查：
1. 是否使用管理员账号登录
2. 网络连接是否正常
3. 浏览器控制台是否有错误信息
4. 操作日志中是否有相关记录

## 联系支持
如有技术问题，请联系系统管理员或查看操作日志获取详细信息。
