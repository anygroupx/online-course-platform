## 🏗️ **项目架构**

### 后端架构（Spring Boot）
```
├── common/                 # 公共模块
│   ├── constant/          # 常量定义
│   ├── exception/         # 异常处理
│   ├── result/            # 统一响应
│   ├── util/              # 工具类
│   └── aspect/            # AOP切面
├── config/                # 配置类
│   ├── SecurityConfig     # Spring Security
│   ├── MyBatisPlusConfig  # MyBatis Plus
│   ├── Knife4jConfig      # API文档
│   └── WebMvcConfig       # Web配置
├── domain/                # 领域模型
│   ├── entity/            # 实体类（6个）
│   ├── dto/               # 请求对象（10+个）
│   └── vo/                # 响应对象（5个）
├── mapper/                # 数据访问层（6个）
├── service/               # 业务逻辑层
│   ├── interface/         # 服务接口（10个）
│   └── impl/              # 实现类（10个）
├── controller/            # 控制器层（12个）
└── security/              # 安全组件（2个）
```

```
├── api/                   # API封装（5个模块）
├── assets/                # 静态资源
├── layouts/               # 布局组件（1个）
├── router/                # 路由配置
```

## 🎯 **技术特点**

### 后端特点
1. **分层架构**: Controller → Service → Mapper，职责清晰
2. **事务管理**: 关键操作使用@Transactional
3. **异常处理**: 全局统一异常处理
4. **参数校验**: @Valid自动校验
5. **安全加密**: BCrypt密码加密
6. **JWT认证**: 无状态认证
7. **AOP日志**: 自动记录执行时间
8. **API文档**: Knife4j自动生成

### 前端特点
1. **组合式API**: Vue 3 Composition API
2. **状态管理**: Pinia轻量级
3. **请求拦截**: 统一Token和错误处理
4. **路由守卫**: 自动登录检查+权限控制
5. **响应式设计**: Element Plus组件
6. **懒加载**: 路由组件按需加载
7. **表单验证**: Element Plus验证
8. **美观UI**: 现代化设计

### 1分钟快速启动

**Windows**:
```bash

2. 双击：start-backend.bat
```
