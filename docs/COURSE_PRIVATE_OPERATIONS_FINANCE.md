# 密价运营中心财务口径

## 本金及账本

课程预存是普通余额转入绑定代理和课程商品的专款账户，不增加真实充值统计，也不确认课程销售收入。首次资格、周期资格和档位升级均不得把本金当会员费、自动没收本金或重复扣取资格费用。

资金以原 `account_ledger`、`course_reserved_wallet_ledger` 和成功 `course_reserved_transfer` 为准。转入先扣普通余额、再增加课程钱包；转回先扣钱包、再增加普通余额，双边使用相同业务单号。金额、流水、划转单或审批执行状态任何一个写入失败，都必须整体回滚。

所有货币入参用 BigDecimal，最大单笔金额及钱包余额为 9999999999.99，最多两位小数。生命周期累计和周期消费使用更宽 DECIMAL，不用前端浮点求财务总和。价格固定到课程商品，不能用上游课程名或一个统一折扣代替成交价。

## 预存资格

NEW_DEPOSIT 首次开通只认审批后真实成功的新增转入。EXISTING_BALANCE 允许使用存量可用余额，须由明确的发布规则选择和代理知情确认。

新增预存续期口径为资格窗口内成功转入减同窗口已批准转回；订单退款、奖励、历史累计充值和当前余额都不能代替新增预存。流水 ID 水位与业务时间窗口同时约束资格，防止审批前后的同秒资金混记。

资金资格分配唯一关联原转入流水，不扣款或冻结本金，但禁止同一资金再满足首次开通、升级和多期续约。`sumNetDeposit` 是原始财务净统计，允许为负；资格评估必须同时检查未认领资金，不能直接把此累计数反复认领。

## 成交和有效消费

订单在支付事务中保存原协议、钱包、周期、周期版本、发布规则版本和实际固定价。退款按原订单支付来源处理，不能根据当前套餐价格重算。

有效消费只计原期支付、存在同额原始扣款、具有可信完成时间并在截止内完成且未退款的净订单金额。充值、转入、转回、跨商品和跨周期订单排除。归档不删除财务事实；逻辑删除的原订单仍需参与结算。

购买窗口是 `[start_at,end_at)`。默认七天结算观察期只等待原订单完成，不延长购买资格。当前周期未结束不能因为现有订单全部完成或没有订单而提前终局。最终结算记录不可覆盖；续期后的退款追加原周期调整和人工复核依据，不追收既往差价，不默认撤销已执行权益。

本期继续支持课程全额退款，不将未来的部分退款、返点或限量配额包装成现有能力。

## 释放申请及财务审批

申请期间不冻结资金，代理仍可消费。提交、撤销或拒绝申请均不产生资金流水，不提前增加普通余额。界面必须明确提示申请不等于已转回。

财务批准需要 `course-wallet-release:review` 和 `course-wallet:release` 两项权限，并核查当前数据库权限和账号状态。事务按用户→协议→钱包→申请锁序重新检查拥有者、绑定及可用金额；消费后余额不足时返回明确错误，申请仍保留 PENDING。

成功执行使用原资金服务并把同一转账 ID 写入申请 EXECUTED 状态，双账本、划转身份和申请状态同事务提交。重复审批返回原执行结果；拒绝、撤销和已执行状态不能相互覆盖。旧接口同键产生的历史转账不能被冒认为当前申请执行。

转回目标是平台普通余额，不是支付宝、银行卡原路退款。支付退款属于独立业务，不能混用接口或文案。已暂停、终止或到期的关系仍保留本金和原订单退款来源。

## 真实成本及发布风险

普通销售 `base_price` 不等于采购成本。成本配置需要核验权限、证据、核验主体、有效期和不可变版本。缺少真实成本显示待配置，不伪造毛利或利润率，不允许新套餐发布。

单位贡献额为固定密价减核验单位成本，贡献率为贡献额除固定密价。它不等于最终净利润，不包括未提供事实依据的平台运营费用、渠道费用、税费或履约异常损失。

固定价不高于核验成本时，须由具有独立风险权限且与草稿维护人和发布执行人不同的审批人批准当前草稿/成本版本。编辑草稿、成本版本变化或提交旧评估版本均不能沿用旧审批。

## 实施状态

当前已实现套餐发布/成本核验与释放审批服务，以及申请首开/重新签约、首次资格认领、延期生效、成交周期绑定、可信履约、有效消费结算及终局后事实复核，并通过真实 Mapper/事务测试和后端全量回归。续约、明确授权补授、同家族升级与独立审核旧协议转换已接入；分析、站内通知、旧入口同步、普通价显式成交和原净事实复核已接入，远程门禁与整体灰度验收仍待完成。

实际履约时间与确认上界独立保存。上游在截止前已经确认原订单完成，可以证明实际完成不晚于该时刻，但实际字段仍保持未知。截止后才观察到且无实际时间的订单不能自动回填；实际时间与先前确认相矛盾时要求复核。普通订单状态编辑不构成可信证据，人工补验需订单修改和结算执行两项当前权限并保存核验依据。

历史退款或其他终局后净事实变化只调整原期统计、追加 REFUND_REVIEW/FACT_REVIEW，不修改原 finalizedAt，不追收历史差价，也不撤回已执行的新周期。源周期未结束时即使零订单或已达标，都不能终局；未完成原订单在默认七天观察期内等待证据。

人工补授保存独立依据，原期金额/未达标状态不被改成达标。升级差额只扣减已证明门槛基数，不能扣减未知旧 N 或把余额冒充新增预存；FULL_TARGET 与 EXISTING_BALANCE 只按对应冻结政策使用。资格认领不移动本金，排程生效前转回会触发资金重验。旧协议转换以申请水位排除未知旧流水，旧订单退款仍回原钱包、按原订单金额。


## 已接入的分析口径

经营分析在一致性只读事务内逐批读取完整证据，不使用浏览器列表加总或过时投影决定有效成交。专户余额按钱包唯一身份计一次，跨多期续期不会重复计本金；待转回只统计PENDING申请，不称冻结金额。

成本覆盖按有效单计数。全部有效单具备发布时绑定的核验成本，才能展示总估算贡献毛利；部分覆盖仅展示已覆盖估算成本及覆盖数，总贡献额保持未知。实际供应商逐单结算尚无完整证据，actualProfit保持null。

资金账龄是完整账本FIFO模型的余额加权天数，非真实供应商资金占用成本。流水期初须为零且每笔前后余额连续一致；退款、未来时间、缺失期初或归属异常使全量平均年龄保持未知，并展示已覆盖本金。新增流水显式使用业务Clock；历史原时间不改写。


原专户对账同时核验成功划转与普通账本反向同额记录、原订单快照、原扣款、每笔余额连续性及最终账面余额。未记录的历史期初属于证据不足；有连续流水却与余额相矛盾属于明确异常。分析只报告，不代替财务授权修复或自动冻结；有证据疑点时账龄与利润保持未知。

按套餐筛选时，成交属于原支付周期，当前本金只属于当前协议绑定的套餐，跨期/升档不会重复计本金。近7/30天激活统计按代理去重；升级率为筛选内已生效升级的唯一协议数除已签约协议数，均明确口径。

明确普通价成交仅使用普通余额；普通订单不计入密价原期消费，也不关联原专户。退款复核确认当前净事实，不把退款后的未达标人为改成达标、不重置原终局、不撤回已授予下一期。
